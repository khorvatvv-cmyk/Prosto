# Android-клиент «Просто»

Android-приложение является нативной оболочкой Capacitor для клиентской части «Просто». Оно использует тот же интерфейс и учётные записи, что и веб-версия, и обращается к production API Cloudflare Worker.

## Требования

- Node.js 22+
- JDK 21
- Android SDK с Platform 36 и Build Tools
- Android 7.0 (API 24) или новее на устройстве

## Сборка APK

```powershell
npm ci
npm run android:apk
```

Команда собирает web-бандл в режиме `android`, синхронизирует его с нативным проектом и создаёт APK:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Адрес API задаётся в `.env.android` переменной `VITE_API_URL`. После изменения web-кода или адреса API следует снова выполнить `npm run android:apk`.

## Установка тестовой сборки

Разрешите установку приложений из выбранного источника на Android, скопируйте APK на устройство и откройте файл. Текущая сборка подписана стандартным debug-сертификатом и предназначена для прямого тестирования. Для Google Play необходимо создать защищённый release-ключ, собрать подписанный Android App Bundle и хранить ключ вне репозитория.

## Безопасность

- незашифрованный HTTP запрещён;
- резервное копирование данных приложения отключено;
- секреты и пароли в APK не встраиваются;
- авторизация выполняется production API через HTTPS.
